# Sprint_5 — UI-тестирование Stellar Burgers

Проект содержит автотесты для сервиса Stellar Burgers (космический фастфуд).
Тесты написаны на Python с использованием Selenium WebDriver и pytest.

## Структура проекта

- `tests/` — файлы с тестами
- `conftest.py` — фикстуры pytest
- `locators.py` — локаторы элементов
- `data.py` — генераторы данных (email, пароль, имя)
- `requirements.txt` — зависимости проекта
